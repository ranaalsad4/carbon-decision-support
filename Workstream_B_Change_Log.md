# Workstream B Change Log: v1.0 (WSB-6.0) → v1.1 (WSB-6.1), 21 Oct 2026

**Purpose.** Align Phases 5–7 with the updated Phase 3 (v1.1) and Phase 4 (v1.1) by moving to the Saudi Electricity Company (SEC) 2024 electricity factor. The engine design, rules, criteria, activity data and diesel and freight factors are unchanged.

| | v1.0 | v1.1 |
|---|---|---|
| Electricity factor | `FAC-ELE-GRID-01`, 614.2 kg CO2/MWh (CO2 only, Climate Transparency 2022, data year 2021) | `FAC-ELEC-SEC-01`, **550 kg CO2e/MWh** (SEC 2024, location-based, `provisional_proxy`), read from `phase4/data/emission_factors.csv` |
| Scope 2 (8,000 MWh) | 4,913.600 tCO2 | **4,400.000 tCO2e** |
| Quantified sum | 5,372.9 t (mixed tCO2 + tCO2e, ranking only) | **4,859.252 tCO2e** (single gas label; indicative, excludes Contractor B) |
| Electricity confidence | LOW | **MODERATE** (C2 Partial, C5 Not met; the label is not HIGH) |
| Tests | 43/43 (11 WSB + 32 Phase 4) | **50/50** (15 WSB + 35 Phase 4) |

The Scope 2 change comes only from the factor change. It is not an emissions reduction, and the two figures are not like-for-like (CO2 vs CO2e). Ember's lifecycle factor (689.051 kgCO2e/MWh) is not used.

**Found during the update:**
- *Confidence label.* Running the unchanged v1.0 code on the new data still scored electricity LOW, but only because `confidence.py` compared the boundary against the old value `grid`. With the Phase 3 boundary name corrected, the documented criteria give MODERATE.
- *Monthly chart.* The v1.0 dashboard's monthly electricity chart filtered on `tCO2` and would have shown an empty chart. Both are fixed.
